# MiniGPTEngine-CPP

An educational C++ transformer experiment with a portable, dependency-free
reference attention kernel and historical GGUF exploration programs.

## Verified kernel

```bash
make test
```

The eight-head kernel computes causal scaled dot-product attention with stable
softmax and identity Q/K/V projections. Its executable checks an independent
numeric reference, future-token isolation, large finite scores, constant-value
preservation and invalid shapes. This lane needs a C++17 compiler, no downloaded
weights, GPU or Apple framework.

## Current model boundary

`real_inference.cpp`, `quick_test.cpp` and `step4_final.cpp` contain canned answer
maps. Those answers are not generated by TinyLlama or a trained transformer.
The historical tokenizer also includes a manually populated vocabulary. These
programs remain available for studying the prototype, but should not be used as
model-quality evidence or presented as real inference in a demo.

`make all` builds the historical programs with portable C++17 flags. The
model-dependent `make test-all` first checks `MODEL_PATH`; it does not validate
trained-model generation. No compression ratio, speedup or latency claim is
established by the reference kernel checks.

Complete model inference still needs verified GGUF tensor decoding, tokenizer
loading, trained projection/MLP layers, positional encoding, normalization,
KV caching and a token sampling loop. A final product demo is blocked until that
lane has model-backed generation and comparison against an independent runtime.
